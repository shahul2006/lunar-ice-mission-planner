# Lunar Ice Mission Planner

Detection and Characterization of Subsurface Ice in Lunar South Polar Regions Using Chandrayaan-2 Radar and Imagery Data for Landing Site and Rover Traverse Planning.

## Overview

This project is being developed for the Bharatiya Antariksh Hackathon 2026.

The objective is to identify potential subsurface water ice deposits in the lunar south polar region using Chandrayaan-2 DFSAR radar and OHRC imagery. The system will also recommend safe landing sites, generate rover traversal paths, and estimate ice volume.

## Objectives

- Detect subsurface ice
- Analyze radar signatures
- Process OHRC imagery
- Select safe landing locations
- Generate rover traversal routes
- Estimate ice distribution
- Visualize results
